# angelortizv — portfolio

Personal site of **Angelo Ortiz Vega** — Technical Lead, Implementations at Silia & AI Engineer. Live at [angelortizv.me](https://www.angelortizv.me).

Built with Gatsby, React and styled-components, deployed on Netlify. The design ("Aurora Studio") and its rules live in [`DESIGN.md`](DESIGN.md). The interactive isometric figure in the _Agent_ section is built with the [Anatomy](https://github.com/wheresryan22/anatomy) kit (MIT), vendored at `src/components/iso/`.

## Development

```bash
pnpm install
pnpm develop   # http://localhost:8000
pnpm build
```
